### 調べて分かった外部仕様（重要・再利用可能）

- **Qt オフスクリーン撮影**：`QT_QPA_PLATFORM=offscreen` で `QMainWindow`/`QDialog` を構築し `widget.grab().save(png)` すれば、**可視ウィンドウを出さず（作業中断なし）に実UIを PNG 化できる**。
- **`QMediaPlayer` の映像フレームは offscreen でも grab に写る**（"No RHI backend. Using CPU conversion." のログ付きで testsrc/gradients が描画された）。
- **波形／メルスペクトログラムは offscreen では実描画されない**：ワーカーは "Loading waveform... 100%" まで進むが、描画スワップに実 GPU サーフェス/実 paint が要る模様。42秒待っても不変。→ **波形付き編集ビューの実スクショはライブ実行 or 開発者提供が必要**。
- ダイアログは自己完結で撮れる：`ExportSettingsDialog(parent=None, available_encoders=[(encoder_id, display_name, description), ...], is_audio_only=False, cover_image=None, work_dir=None)` / `PreferencesDialog(parent=None)` / `BatchEncodeDialog(work_dir, parent=None)`。
- ソース読込＋波形起動の入口：`MainWorkspace.load_video_file(path: Path)`（→ `_load_source_media` / `_start_waveform_generation`）。`Chaptr` は `self._workspace` に保持。
- 撮影用サンプル生成：`ffmpeg -f lavfi -i "gradients=s=1280x720:...:d=120" -f lavfi -i "aevalsrc=(0.5+0.45*sin(2*PI*0.10*t))*(倍音):d=120:s=48000"` ── 振幅変調で波形に濃淡が出る構造化オーディオ。

## 04:20 — v2.3.0 Release 公開（Windows ビルド修復＋単一 exe 化）

### TL;DR

`v2.3.0` タグで Release を起動 → **初回 Windows ビルド失敗（MSVC `C1002` ヒープ枯渇）**。原因は**未使用 yt-dlp の同梱**。`release.yml` から yt-dlp を全廃（commit `c607922`）して再ビルド → 全4ジョブ成功・**Release 公開**。さらに要望で**配布物を zip 梱包から単一 `.exe` へ**変更。

### 顛末

- 初回 run：macOS(Intel/ARM) 成功、**build-windows 失敗** → release スキップ（未公開）。エラー verbatim：
  ```
  module.yt_dlp.extractor.lazy_extractors.c(231106) : fatal error C1002: compiler is out of heap space in pass 2
  FATAL: Failed unexpectedly in Scons C backend compilation.
  ```
- yt-dlp は**コード未参照・pyproject 依存にも無い残骸**（YouTube DL 機能削除後）。Windows の Nuitka が `--include-package=yt_dlp` で巨大生成C（`lazy_extractors` 23万行）を吐き、`cl.exe` がヒープ枯渇。macOS は clang なので通過していた（CI で初めて発覚）。
- 修正 `c607922`：`release.yml` から yt-dlp を全廃（pip×3・Nuitka include・`yt-dlp.exe` DL/zip 同梱）。`v2.3.0` を張り直して再ビルド → **成功**。
- **単一 exe 化**（要望）：`--onefile` なので中身は元々単一 `Chaptr.exe`（ffmpeg も data-dir で内包）。zip 梱包を廃止し、`Video-Chapter-Editor-<ver>-Windows.exe` をそのまま Release 添付する形へ（`release.yml`「Create ZIP」→「Rename to versioned exe」、softprops `files` を `*.zip`→`*.exe`）。README も配布表記を「配布しています」に更新＋Release バッジ＋「Windows は単一 `.exe`」表記。

### 学び（重要・再利用可能）

- **Nuitka + yt-dlp on Windows は `C1002` の定番地雷**：yt-dlp の `lazy_extractors` が超巨大な生成Cになり MSVC がヒープ枯渇。使っていないなら同梱しない。macOS(clang) では顕在化しないので CI で初めて出やすい。
- `--onefile` Nuitka の成果物は単一 exe。zip 梱包は不要。
