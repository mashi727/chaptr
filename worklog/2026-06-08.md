### 重要な決定と理由

- **Noto Sans JP / Bold / リポジトリ同梱**（ユーザー判断）→ 単一フォントファイルで Qt と ffmpeg を駆動でき WYSIWYG を保証。同梱により他環境・PyInstaller バンドル・他OSでも同一描画を保証（既存の `detect_system_font` 方式はOS依存でフォールバックが崩れる）。
- **静的ウェイト別 OTF を採用（可変フォント不採用）** → ffmpeg/libfreetype は可変フォントのウェイト軸(`wght`)指定が不安定で、drawtext で意図したウェイトが出ない懸念があるため。
- **単一情報源を `models.get_overlay_font_path()` に集約** → 焼き込み2ワーカーが既に `..models` を import 済みで、プレビュー側(`main_workspace`)も同 import 可能。ウェイト変更時は `OVERLAY_FONT_FILENAME` の差し替え＋同梱ファイル置換のみで両側に反映。
- **同梱→なければ `detect_system_font()` にフォールバック** → 万一バンドル漏れでも従来挙動を維持。
- **`.gitignore` の例外行は不要** → `.gitignore` は png/jpg/mp4 等のみ除外し `.otf` は対象外（`git check-ignore` で tracked-able を確認）。前回のアイコン(png)とは事情が異なる。
- **legacy `chaptr/ui/workers.py` は対象外** → 同階層に `workers/`（パッケージ）が存在し、Python のパッケージ優先で `workers.py` は完全にシャドウされた dead code（`from .workers import` はすべてパッケージに解決）。前回ログでも削除候補とされている。
- **main 直コミット** → 既定ガイドは「default branch なら branch を切る」だが、本リポジトリは直近コミットもすべて main 直運用かつユーザーが明示的に commit & push を指示したため main に直接コミット。

### ハマった点・エラーと回避策

- **現象**：`QFontDatabase.addApplicationFont('chaptr/ui/fonts/NotoSansJP-Bold.otf')` が `id = -1`（`families = []`）を返し失敗、続く `applicationFontFamilies(fid)[0]` で `IndexError: list index out of range`。
- **原因**：**相対パス**で渡したため Qt がファイルを解決できなかった（cwd 依存）。同じファイルを**絶対パス**で渡すと `id=0`・`families=['Noto Sans JP']` で成功。
- **解決**：`get_overlay_font_path()` は `Path(__file__).resolve().parent / "fonts"` で**絶対パス**を返す実装にし、`get_overlay_font_family()` 側も `str(path)`（絶対）を渡す。`addApplicationFont` 失敗時は family 空文字 → CSS で font-family 省略フォールバック、と防御的に実装。
- **副次**：Pyright が `sys._MEIPASS` を `reportAttributeAccessIssue` と警告するが、既存 `get_icon_path()` と同じ PyInstaller 用パターンで想定内（実害なし）。export.py / export_split.py の `readline`/`None` 系警告はいずれも本変更と無関係の既存診断。

追加した中核関数（`models.py`）:

```python
OVERLAY_FONT_FILENAME = "NotoSansJP-Bold.otf"
OVERLAY_FONT_FAMILY = "Noto Sans JP"

def get_overlay_font_path() -> str:
    if getattr(sys, "frozen", False):
        base = Path(sys._MEIPASS) / "chaptr" / "ui" / "fonts"
    else:
        base = Path(__file__).resolve().parent / "fonts"
    bundled = base / OVERLAY_FONT_FILENAME
    if bundled.exists():
        return str(bundled)
    return detect_system_font()
```
