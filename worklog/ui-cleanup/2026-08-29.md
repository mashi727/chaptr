### 重要な決定と理由

- **削除の境界は「ダウンロード経路」のみ** — チャプターのYouTube形式（`Copy to Youtube`、`.txt`出力、`Cmd+V`での貼付けパース）は用途が別。README の YouTube 記述を確認したところ**すべてチャプター形式側**で、ダウンロード機能の記述は無かった。CHANGELOG は過去リリースの履歴なので改変しない。
- **出力ファイル名は内部文字列へ** — 単純削除するとエクスポート先が決まらない。元々 `_update_base_filename_from_first_source()` が自動導出（単一ソース＝ファイル名、複数＝作業フォルダ名）しており、`QLineEdit` はその上書き手段にすぎなかった。`self._output_base` ＋ `output_base()` を唯一の情報源にし、プロジェクトの `output_base` キーの保存/読込もそのまま維持。
- **`yt-dlp` を依存から外す** — GUI から使う箇所が無くなったため。`bin/yt-srt`（字幕取得の別CLI）は Python パッケージの依存ではないので影響しない。
- **アスペクト比ロックの撤去** — もともと動画エリアを16:9に保つためのものだった。動画コンテナ自体を16:9にした時点で目的が消え、残すと自由なリサイズを妨げるだけになる。幅は区間表示の時間分解能に、高さは周波数分解能に直接効くので、用途に応じて自由に取れる方がよい。
- **UI拡大は `QT_SCALE_FACTOR`** — 個々の寸法を書き換える方式では、スタイルシートに散在する `px` 指定が追従せず破綻する。`QApplication` 生成前に環境変数で設定すれば、フォント・ウィジェット・px指定がまとめて拡大される。`os.environ.setdefault` にして外から上書きできるようにした。
- **動画は「幅から高さを決める」** — stretch で按分すると動画の縦横どちらかが必ず余る（縦が余れば左右に、横が余れば上下に黒帯）。幅を基準に16:9の高さを与えれば無駄が出ない。
- **起動時の stdout デバッグ出力を削除** — `showEvent` → `_print_video_size()` が毎回 `Video container size: ...` 等4行を標準出力へ書いていた。動画が常に16:9になった時点で用途も消えた。
- **テーマ/スペクトログラム設定の変更ハンドラを下段にも適用** — `_on_theme_changed` / `_on_spectrogram_changed` が上段しか再描画しておらず、下段が古いまま残る不具合があった（下段はカラーマップ名こそ独自だが彩度・明度はテーマ設定を使う）。

### 検討して採らなかった選択肢と理由

- **ウィンドウ比を 4:3 に固定して動画エリアを16:9に保つ** — 実測では4:3上でのみ16:9近傍（ずれ−24〜+32px）に留まり有効で、1400×1050 では誤差2pxまで追い込めた。だが動画コンテナ自体を16:9固定にした時点で不要になり、比率ロックごと撤去した。
- **`VIDEO_HEIGHT` による固定サイズ（568×320）** — 完全に決定的で字幕パネルの表示切替にも揺れないが、「めっちゃちっちゃくなりやしたぜ！」。ウィンドウを大きくしても追従しないのも難点。
- **動画と波形を stretch で按分（5:4 / 1:1 / 4:5 / 3:5 を実測）** — どの比でも動画の縦横どちらかが余る。最終的に「幅から高さ」方式に置換。
- **`heightForWidth` によるレイアウト折衝** — Qt が尊重せず最小高さで潰れた（詳細は region-view 側の「調べて分かった外部仕様」）。
- **CHANGELOG の過去エントリから YouTube 記述を消す** — 過去リリースの履歴であり、事実の改変になるため触らない。

### ハマった点・エラーと回避策

**1. 削除した機能のテストが収集エラーになる**
```
ERROR collecting tests/test_youtube_mixin.py
E   ModuleNotFoundError: No module named 'chaptr.ui.youtube_mixin'
```
→ 削除した機能のテストなので `tests/test_youtube_mixin.py` も削除。

**2. `NameError: Error calling Python override of QFrame::sizeHint(): name 'QSize' is not defined. Did you mean: 'QSizeF'?`**

`main_workspace.py` の Qt import が `QSizeF` のみで `QSize` を含んでいなかった。

**3. 動画枠のサイズ決定で3回外した**

- 固定320px → 小さすぎ（「動画がめっちゃちっちゃくなりやしたぜ！」）
- 16:9内接＋stretch按分 → 波形が潰れる（1400×900 で 70/104）。原因は子への `setFixedSize` が親の最小サイズへ伝播して stretch を上書きしていたこと。コンテナをレイアウトから外し手動配置にして解決。
- 配分4:5（波形を大きく） → 「全然ダメやね。」。**「1つ前の波形の高さに戻す」を大きくする方向と読んだが、対象のスクリーンショットの波形は逆に小さく（上約70/下約104）動画が幅いっぱいだった。**
- 最終: 幅から高さを決める方式で目標値（動画1059×596、波形72/108）を再現。

**4. `resizeEvent` の早期 `return` でコンテナが古い寸法のまま残る**

枠は正しく 892×505 と計算できていたのに、高さを変えた回に `return` で抜けて `refresh_content_size()` を呼ばず、コンテナが 631×355 のままだった。高さを変えた回も必ず追従させるよう修正。

**5. レイアウト実測は `show()` しないと反映されない**

`resize()` だけでは viewport が既定値（400×300）のままで、どのウィンドウサイズでも同じ値が返ってきた。`win.show()` ＋ `app.processEvents()` を複数回まわす必要がある。
