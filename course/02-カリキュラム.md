# カリキュラム構成案 — 「Claude Codeで実用デスクトップアプリを作る」

> `course/01-開発ストーリー.md` の6フェーズを、Udemyのセクション/レクチャー単位に落とし込んだもの。
> 各レクチャーに「所要時間の目安・種別・対応する実際のコミット」を紐づけてある。
> Udemyの推奨：1レクチャー2〜7分、1セクション合計10〜30分。トータルで**動画3〜4時間**規模を想定。

---

## コースのコンセプト

**タイトル案（3案）**
1. 「Claude Codeで作る実用デスクトップアプリ 〜MVPから配布・保守まで〜」
2. 「AIペアプロで1ヶ月：動画編集アプリをゼロから配布まで作った全記録」
3. 「Claude Code実践：Python + PySide6デスクトップアプリ開発の現場」

**サブタイトル / 一文サマリ**
> 「動くもの」で終わらせない。MVP→クロスプラットフォーム配布→大規模リファクタ→実戦バグ潰しまで、実際のgit履歴をなぞって学ぶ。

**ターゲット受講者**
- Pythonの基礎はある（if/関数/クラスがわかる）
- 個人開発・自作ツールをちゃんと「配れる」形にしたい
- AIコーディング(Claude Code)を「なんとなく」から「戦力」にしたい人

**受講者が得られるもの（Udemyの "What you'll learn"）**
- Claude Codeで実アプリを設計・実装・デバッグ・配布する一連の流れ
- PySide6 + ffmpeg でのGUI/メディア処理の実装パターン
- GitHub ActionsでmacOS/Windowsバイナリを自動ビルドする方法
- 肥大化したコードを managers/controllers/workers に分割するリファクタ手法
- Claude Codeを効果的に使うコツ（CLAUDE.md、Explore、AskUserQuestion、worklog運用）

**前提・非対象（明記して期待値調整）**
- ○ 対象：Claude Codeの実戦的な使い方、アプリ開発の全工程
- × 非対象：Python文法のゼロ入門、機械学習/Whisperの内部実装

## 制作上の指針

### 難易度カーブ
MVP（易）→ 配布（難・泥臭い）→ リファクタ（構造的）→ デバッグ（実戦）→ 磨き込み（応用）。
中盤の配布地獄で挫折しないよう、Section 4冒頭で「ここは誰もが詰まる。詰まって正常」と先に言う。

### 各レクチャー共通テンプレ（`course/03`で台本化）
1. **今日のゴール**（15秒）
2. **なぜこれが必要か**（30秒、対応する実際の困りごと）
3. **実演**（本体）
4. **Claude Codeへの指示の実際**（プロンプトを画面に出す）
5. **ハマりどころ**（30秒）
6. **次回予告**（10秒）

### 収録スタイルの推奨
- 実際のgit履歴のタグに `git checkout` しながら進めると、各段階の状態を再現できる（→ `course/04`）。
- Claudeとのやり取りは**編集で早送りしつつ、指示文（プロンプト）は静止で読ませる**。
- エラー画面は**必ず一度フルで見せてから**解説（受講者が同じエラーを検索で見つけられるように）。

### 収録しない/軽く流すもの
- Python文法そのもの（前提とする）
- Whisper/LaTeXの内部（関連プロジェクトとしてリンク紹介に留める）
- 2/18の9コミットの中身を1行ずつ追うこと（構造の話に絞る）

### MVP版コース（もし短く出すなら）
Section 0,1,2,4,7 だけで「MVP→配布→デバッグ」の最小ストーリーが成立（約1.6時間）。
まず短縮版を出して反応を見てから、配布地獄(5)とリファクタ(6)を追加リリースする戦略も可。
