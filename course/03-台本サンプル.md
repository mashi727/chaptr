## L8.2 日本語の罠：濁点分離をNFC正規化で直す

```
export.py と export_split.py の両方。
```
🎬 修正:
```python
import unicodedata
title = unicodedata.normalize("NFC", title)
```
🎬 再エクスポート→濁点が正しく結合。
🗗️ 「実際のコミット`23edd5e`も、export.pyとexport_split.pyの2ファイルを直しています。焼き込み経路が2つあるのを忘れない。」

## スライドの作り方（共通ガイド）

### スライド枚数の目安
1レクチャーあたり **タイトル1 + 概念2〜4枚**。実演中心なので画面共有が主役、スライドは節目だけ。

### スライド・テンプレ（4種）
1. **概念スライド**：見出し＋3点以内の箇条書き。文章を書かない。
