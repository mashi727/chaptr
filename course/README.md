# course/ — Udemyコース教材

**主題は「上流設計＝コードを書き始める前に決めること」。** Chaptrはそれを説明する題材（case study）。
うまく決めた所・決め損ねた所の**両方**を証拠に、着手前の意思決定を1枚のキャンバスに落とす方法を教える。

## 読む順番

1. **00** で上流設計キャンバス（10領域）と12原則を掴む ← コースの思想の中心
2. **02** で12章立てのセクション/レクチャーを確認
3. **01** を証拠カタログとして参照（各ケース章の `git show`・worklog・数字はここから）
4. **03/04** を上流設計版に改訂 → 収録

## このコースの核

世の教材は **how to build（作り方）** に偏る。だが破綻はたいてい**書き方でなく、着手前の決め損ね**から起きる。
Chaptrの履歴はその証拠の宝庫——**名前を2回変え（命名を後回し）、配布に15コミット費やし（配布を後で考え）、1pxのバグを生んだ（データ契約が曖昧）**。
本コースは「先に決めておけばこの代償は避けられた」を実データで示し、その意思決定を**キャンバス→CLAUDE.md→判断ログ**に落とす技術を教える。

> 合言葉：**決定を、コードでなく文章で外在化せよ。**
