# course/ — Udemyコース教材

Chaptr を Claude Code で作った過程を、Udemy動画コースにするための教材一式。

## 中身

| ファイル | 内容 | 使う人 |
|---|---|---|
| [`01-開発ストーリー.md`](./01-開発ストーリー.md) | git履歴+CHANGELOG+worklogから復元した開発物語（6フェーズ・12原則）※worklogはフェーズ5のみ実在 | 全体の背骨。まずここ |
| [`02-カリキュラム.md`](./02-カリキュラム.md) | 9セクション43レクチャーの構成案・所要時間 | コース設計 |
| [`03-台本サンプル.md`](./03-台本サンプル.md) | 代表レクチャーの完全台本＋スライド指針 | 収録原稿 |
| [`04-リポジトリ整備.md`](./04-リポジトリ整備.md) | 追体験用タグ設計・演習課題・収録手順 | リポジトリ準備 |
| [`exercises/`](./exercises/) | 演習用データ（S7のバグ再現チャプター等） | 受講者 |

## 読む順番

1. **01** で物語と「教えたい12原則」を掴む
2. **02** でセクション/レクチャーに落とす
3. **03** のフォーマットで各回を台本化
4. **04** でリポジトリを追体験可能に整備 → 収録

## このコースの核

「動くもの」で終わる入門動画は多いが、Chaptrの履歴には
**MVP → クロスプラットフォーム配布の壁 → 大規模リファクタ → 実戦バグ潰し → リブランド**
という開発の全工程が本物の形で残っている。その泥臭さこそが差別化ポイント。
